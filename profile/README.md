# UNION OF FREEDOM (UOF)

> *"LOOKING FOR THE FREEDOM WITH A CODE".*

**UNION OF FREEDOM (UOF)** is an independent security research and systems engineering collective focused on low-level internals, hardware side-channel analysis, and practical defensive tooling.

---

## Core Research Pillars

* **Hardware & Side-Channel Security:** Investigating physical telemetry, processor power/thermal behavior, and hardware-rooted anomaly detection (including the **Volt-Ghost** and **VoltySecure** research lines).
* **Low-Level Systems & Kernel Internals:** Analyzing operating system behavior, memory safety, and low-level execution mechanics across Linux and Windows environments.
* **Defensive Engineering & Tooling:** Building practical detection utilities, mitigation scripts, and reproducible technical writeups.
